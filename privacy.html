プライバシーポリシー

Nius-G（以下「運営者」）は、配信支援アプリ「こめろぐ！」および公式サイトにおける情報を、以下の方針で取り扱います。本ポリシーは、アプリ、公式サイトおよびお問い合わせに適用されます。

1. 取得する情報と利用目的

配信サービスと連携した場合、チャンネル情報、配信情報、コメント、投稿者の表示名・識別子、応援イベントなどを取得します。これらは配信の記録、お礼カードやエンドロールの制作、配信やリスナー履歴の振り返りに利用します。取得される情報は、連携先や許可した権限、配信の状況によって異なります。

アプリで入力したメモや設定、追加した素材は、利用者が選んだ機能の提供や制作物の作成に利用します。

2. Google API・YouTube API Services

こめろぐ！のYouTube連携では、Google LLCのYouTube API Servicesを利用し、チャンネル名や識別子、配信タイトル・状態、ライブチャットの投稿者名・識別子・コメント・投稿時刻、対応する応援イベントを読み取ります。読み取り権限（youtube.readonly）は、配信の記録、お礼カードやエンドロールの表示、配信やリスナー履歴の振り返りに使用します。

Googleの認証はGoogleの画面で行います。更新用の認証情報は、Windowsの保護機能を利用して端末に保存します。配信のセッションログも利用者の端末に保存されます。

利用者は、アプリの連携解除操作またはGoogleアカウントの接続設定からアクセス権を取り消せます。連携解除と端末内のデータの削除は別の操作です。

Googleによる情報の取り扱いについては、Googleプライバシーポリシーをご確認ください。YouTubeの利用にはYouTube利用規約も適用されます。Google APIから取得した情報の使用や転送には、使用制限に関する要件を含むGoogle APIサービスのユーザーデータポリシーが適用されます。

3. Twitchとの連携

Twitchとの連携では、配信状態やコメント、対応する応援イベントなどを取得し、配信記録や関連機能に利用します。Twitchにおける取り扱いは、Twitchのプライバシーポリシーをご確認ください。

4. お問い合わせとライト版の通知

アプリから送信された不具合報告や要望は、入力された内容、名前や連絡先、アプリの版・バージョン、送信元を識別するための識別子、および添付が選択された診断情報を、運営者が確認するためDiscordのWebhookを通じて送信します。内容の確認、回答、調査および改善に利用します。不具合報告の診断情報には、アプリや接続の状態などが含まれる場合があります。

ライト版では、利用状況の確認のため、インストール識別子、利用回数、判定結果、アプリのバージョン、日時などをDiscordに通知する場合があります。Discordにおける取り扱いは、Discordのプライバシーポリシーをご確認ください。

5. データの保存と共有

配信記録や設定は利用者の端末に保存されます。TwitchとYouTubeの両方を利用する場合、それぞれの配信情報が同じセッションログに記録されることがあります。利用者が作成した画像や動画を投稿した場合、投稿先を通じて内容が共有されます。外部サービスに保存された元データの削除は、それぞれのサービスで行ってください。

6. 公式サイト

公式サイトはGitHub Pagesを利用しています。GitHubはセキュリティ目的でアクセスした方のIPアドレスを記録します。詳しくはGitHubのプライバシーに関する案内をご覧ください。

7. 配布・販売

本アプリの配布・販売にはBOOTHを利用します。購入やダウンロードの際の情報は、BOOTHの仕組みおよび同サービスの規約・プライバシーポリシーに従って取り扱われます。
